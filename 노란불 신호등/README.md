# 노란불 신호등 (2025 카카오 하반기 1차)
 
## 문제 설명
 
어떤 도로에 차량 신호등이 `n`개 있습니다. 모든 신호등은 항상 **초록불 → 노란불 → 빨간불** 순서로 반복되며, 각 신호의 지속 시간은 신호등마다 다릅니다. 시간은 **1초부터** 시작하며, 각 신호등은 처음에는 **초록불** 상태로 시작합니다.
 
이 도로에서는 가끔 정전이 일어나는데, **모든 신호등이 모두 노란불이 되면 정전이 발생**한다는 사실이 밝혀졌습니다.
 
예를 들어 신호등이 2개이고, 각 신호등의 주기가 다음과 같다고 가정해 보겠습니다.
 
| 신호등 | 초록불 | 노란불 | 빨간불 |
| :----: | :----: | :----: | :----: |
| 1번 | 2초 | 1초 | 2초 |
| 2번 | 5초 | 1초 | 1초 |

 
위 그림과 같이 **13초**에 처음으로 두 신호등이 모두 노란불이 됩니다.
 
신호등 `n`개의 신호 주기를 담은 2차원 정수 배열 `signals`가 매개변수로 주어집니다. 모든 신호등이 노란불이 되는 **가장 빠른 시각(초)**을 return 하도록 `solution` 함수를 완성해 주세요. 만약 모든 신호등이 노란불이 되는 경우가 존재하지 않는다면 `-1`을 return 해주세요.
 
---
 
## 제한사항
 
- `2 ≤ signals의 길이 = n ≤ 5`
- `signals`의 원소는 `[G, Y, R]` 형태의 길이가 3인 정수 배열입니다. 순서대로 초록불, 노란불, 빨간불의 지속 시간을 의미합니다.
  - `1 ≤ G, Y, R ≤ 18`
  - `3 ≤ G + Y + R ≤ 20`

## Solution 1
초록불, 빨간불은 0, 노란불은 1로 생각해서 '00100' 과 같이 문자열로 변경.
총 길이도 구해서 index = time % total_time 으로 각 time 마다 노란불 여부 확인.
각 신호등 마다 위 작업 반복해서, 이들을 다 더했을 때 신호등 개수와 같으면 모든 신호등이 노란불이라는 의미이므로, 그 때의 time을 반환.

이때, 한 번 루프(초록->노랑->빨강)의 총 길이가 같은 애들만 돌려서 안된다 = 아무리 돌려도 안 되는 케이스이므로 -1 반환.

시간 초과가 나는 경우 = 무한 루프 문제 발생
주기가 달라도 영원히 안 겹칠 수 있는 케이스 간과함.

## Solution 2
Solution 1 에서 무한 루프를 최소 공배수로 바꿈.
최소 공배수 도입하면 앞에서 주기 같은 애들 검사하는 부분은 통째로 지워도 됨.
최소 공배수 복잡하게 구하기 싫어서 
`if all(time % total_time == 0 for total_time in total_times) : ` 로 전원 초기 상태로 돌아왔는지,
즉 하나의 큰 루프를 돌았는지 = 최소 공배수만큼 돌았는지를 검사함.
이렇게 하니 코드가 훨씬 간결해졌지만, 매번 for 루프 돌 때마다 검사하는 게 늘어서 다른 테스트들의 시간이 좀 늘었다.
